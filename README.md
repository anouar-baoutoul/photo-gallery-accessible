# Photo Gallery Accessible

Ce projet est une galerie photo interactive et accessible, réalisée dans le cadre du projet final de web design.  
Fonctionnalités principales :
- 6 images avec balise alt pour l’accessibilité
- Navigation clavier avec `tabindex` + gestion des évènements JS (`focus`, `blur`, `mouseover`, `mouseleave`, `onload`)
- Code validé sur W3C, WAVE et aXe
- Structure HTML sémantique (<main>, titres, figures)
- Démo hébergée sur GitHub Pages

## Validation
Le site a été testé et validé sur :
- [W3C Markup Validation Service](https://validator.w3.org/)
- [WAVE Web Accessibility Evaluation Tool](https://wave.webaim.org/)
- [aXe Accessibility Tool](https://www.deque.com/axe/)
